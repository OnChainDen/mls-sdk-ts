# MLS TypeScript SDK

TypeScript SDK for interacting with Den's Multi-Layer Security (MLS) Wallet.

## Multi-Layer Security Wallet

Den is the exclusive provider of Multi-Layer Security Wallet. MLS Wallet is the most secure way to store digital assets. MLS use cases include:

- Wallet-as-a-Service (WaaS) for issuing secure wallets to your customers
- Internal operations for managing treasury, payments, and on-chain workflows

## Documentation

For details on how MLS works and how to get started, check out our [documentation](https://docs.mls.onchainden.com/).

## Get Started

Contact the Den team at [support@onchainden.com](mailto:sales@onchainden.com) to get API access, and follow our [quickstart guide](https://docs.mls.onchainden.com/api-reference/quickstart) to get started.
